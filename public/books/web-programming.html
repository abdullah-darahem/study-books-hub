1.1

Internet, HTTP, URL & Servers

إيه اللي بيحصل لما تكتب URL وتدوس Enter؟

The Internet is a global network of billions of computers and devices that exchange data using a protocol called HTTP (Hypertext Transfer Protocol). HTML (Hypertext Markup Language) was created to write the pages, and the first web browser and web server were created to bring them together.

  • Web browser: fetches and displays documents from web servers (Firefox, IE, Safari, Chrome, Opera).
  • HTTP: a set of commands understood by a web server and sent from a browser: GET filename = download · POST filename = send a web form response · PUT filename = upload.
  • URL (Uniform Resource Locator): identifier for the location of a document on a web site, e.g. http://dept.ju.edu/cs/index.html.

4display the resulting page

Web languages: HTML writes web pages · CSS gives stylistic info · PHP (PHP Hypertext Processor) dynamically creates pages on the server · JavaScript makes pages interactive and programmable · MariaDB is the MySQL clone.

A full-stack developer develops both client and server software: HTML/CSS + program a browser (JavaScript, jQuery, Angular, React, Vue) + a server (PHP, ASP, Python, Node) + a database (SQL, SQLite, MongoDB).

عالشرح بالعربيمن الكيبورد للشاشة في ٤ خطوات
  • الـ Internet = شبكة عالمية فيها مليارات أجهزة بتتكلم مع بعض بلغة اسمها HTTP.
  • الـ browser (Chrome مثلًا) = بيجيب الصفحة من السيرفر ويعرضها. والـ web server (Apache) = قاعد مستني طلبات ويرد بالصفحات.
  • أوامر HTTP: GET = هات (تحميل) · POST = خد الفورم ده (إرسال بيانات) · PUT = ارفع الملف.
  • لما تكتب URL: ١) الـ browser يسأل الـ DNS «عنوان الموقع ده IP بتاعه كام؟» (زي دليل التليفونات 📒) ← ٢) يتصل بالـ IP ده على port 80 ← ٣) يطلب الملف بـ GET ← ٤) يعرض الصفحة.
  • Web server vs Application server: الـ web server بيقدّم صفحات (HTTP بس، ومعظمها static). الـ application server بيشغّل تطبيقات كاملة، ومش محصور في HTTP.
  • Static = منيو مطبوع، نفس الورقة لكل الناس. Dynamic = الجرسون بيكلّمك بالاسم وبيقولك «طلبك المعتاد؟»، الصفحة بتتغير حسب مين اللي طالبها (زي صفحة الفيسبوك بتاعتك).
  • اللغات: HTML = الهيكل 🦴 · CSS = الشكل 💅 · JavaScript = الحركة والتفاعل 🕺 · PHP = الشغل على السيرفر 🧠 · MariaDB = الداتا 🗄️.

1.2

HTML Basics: Structure, Elements & Attributes

الهيكل اللي لازم يبقى في كل صفحة

HTML = Hyper Text Markup Language: the standard markup language for creating web pages; it describes the structure of a web page. It consists of a series of elements that tell the browser how to display content. Saved with extension .html. Tools: a text editor (VS Code, Atom) and a browser.

<!DOCTYPE html>
<html>
  <head>
    <title>Page title</title>   <!-- information about the page -->
  </head>
  <body>
    <!-- page contents -->
  </body>
</html>
  • An element = start tag + content + end tag: <p>This is a paragraph</p>.
  • Attributes give extra information: <element attribute="value">content</element>, e.g. <a href="page2.html">Next page</a>.
  • Some tags have no content and are opened and closed in one tag (self-closing): <hr />, <br />, <img ... />.
  • Nesting: a closing tag must match the most recently opened tag. The browser may render bad nesting anyway, but it is invalid HTML.
  • Comments: <!-- ... -->: useful for disabling sections; cannot be nested and cannot contain --.
  • HTML is not case-sensitive (<P> = <p>), but lowercase is the convention.
عالشرح بالعربيhead = معلومات · body = اللي بيظهر
  • أي صفحة HTML عبارة عن علب جوّه علب: html هي العلبة الكبيرة، وجوّاها head و body.
  • الـ head = معلومات عن الصفحة مش بتظهر جوّه الصفحة نفسها: العنوان (title)، والـ CSS، والـ meta. الـ body = كل اللي اليوزر بيشوفه.
  • الـ element = tag فتح + محتوى + tag قفل. والـ attribute = معلومة زيادة جوّه tag الفتح: href="...".
  • فيه tags مالهاش محتوى، فبتتقفل في نفس الـ tag: <br /> و <hr /> و <img />. سؤال Mid 2026: «The <img> tag requires a closing tag» ← False.
  • الـ nesting: آخر واحد اتفتح هو أول واحد يتقفل، زي العلب الروسي 🪆. <p><b>..</p></b> ← غلط.
  • الـ HTML مش case-sensitive (Mid 2026: False). بس اكتب small دايمًا عشان تبقى شيك.
🪆
Nesting صح: <p><b>مرحبا</b></p> ✅Nesting غلط: <p><b>مرحبا</p></b> ← الـ browser هيعرضها وهو بيعيّط 😭

2.1

CSS Syntax & The 3 Ways to Add CSS

selector { property: value; } · external · internal · inline

CSS (Cascading Style Sheets) describes the appearance, layout and presentation of information on a web page: how information is displayed, not what is displayed (HTML describes the content). It can be embedded in HTML or placed in a separate .css file. With an external stylesheet you can change the look of an entire website by changing one file. CSS is connected to the DOM.

p {
  color: red;
  text-align: center;
}
selector points to the element · { declaration block } · property : value · declarations separated by ;

A CSS rule = selector + declaration block. Each declaration = a property name and a value separated by a colon; declarations are separated by semicolons.

WayWhereUse
External<link rel="stylesheet" href="styles.css"> in the head (as many links as you like)style the whole site from one file
Internalinside a <style> element in the headone page with a unique style
Inlinethe style attribute on the element: <h1 style="color:blue;">a unique style for a single element

Cascading order (highest priority first): inline style → external and internal styles (in the head; the last one read wins) → browser default. So an inline style overrides external and internal styles and browser defaults.

عالشرح بالعربيالأقرب للعنصر هو اللي بيكسب
  • القاعدة: selector { property: value; }. الـ selector = مين اللي هنغيّره · الـ property = إيه اللي هنغيّره · الـ value = هيبقى إزاي. سؤال 2024: «correct format» ← selector {declaration}.
  • ٣ طرق تحط بيها CSS:
    • External = ملف .css لوحده وتربطه بـ <link>. ميزته: تغيّر شكل الموقع كله من ملف واحد 🎯.
    • Internal = جوّه <style> في الـ head (Final 2025: «internal style sheet» ← <style>).
    • Inline = style="" على العنصر نفسه (كويز المنصة: «attribute specifies inline CSS» ← style).
  • مين بيكسب لو فيه تعارض؟ الأقرب للعنصر. الـ inline مكتوب على العنصر نفسه، فهو الأقوى. وبين الـ external والـ internal: اللي اتقرا الأخير هو اللي بيكسب.
👨‍👩‍👦
Cascading order: الـ browser default = القواعد العامة · external = كلام بابا · internal = كلام ماماinline = إنت شخصيًا لابس اللي إنت عايزه 😎 ← هو اللي بيكسب

SelectorSyntaxSelects
Typep { }all elements with that name

An element can have more than one class: <p class="center large">. The id is unique within a page: use it once; use a class for many elements. Categories: simple selectors (name, id, class) and combinator selectors (relationship between elements, e.g. descendant).

عالشرح بالعربي# للـ id · نقطة للـ class
  • Type = اسم الـ tag: p بيلوّن كل الـ paragraphs.
  • id = # + الاسم. الـ id زي الرقم القومي: مايتكررش في الصفحة. سؤال Mid 2026: «id attribute can be used multiple times in one page» ← False. ومايبدأش برقم.
  • class = . (نقطة) + الاسم. الـ class زي لون التيشيرت في الفريق: كذا عنصر يلبسوه. والعنصر الواحد ممكن ياخد كذا class: class="center large".
  • p.center = الـ p بس اللي عليها class center، والـ h1 اللي عليها نفس الـ class مش هتتأثر.
  • Descendant (مسافة): p b = الـ b اللي جوّه p بس. ومثال المحاضرة: ol ol = لستة جوّه لستة تبقى بحروف (a, b, c).
  • Grouping (فاصلة): h1, h2, p = نفس الستايل للتلاتة بدل ما تكرره ٣ مرات.
  • ⚠️ فرّق: p b (مسافة = جوّه) و p, b (فاصلة = الاتنين).

div Layouts & The Box Model
margin ← border ← padding ← content

  

    
<div> defines a division or section: a container for HTML elements, styled with CSS (via class or id) or manipulated with JavaScript; any content can go inside. Divs are used to create page layouts: tables can also make layouts, but they are very complex to modify; the div is flexible and easy to modify.

    
Box model, from the outside in: margin → border → padding → content. Margin separates elements from each other; padding is inside the border.

    

      
Values givenMeaning (margin / padding / border-width)

      
1pxall four sides

      
1px 2pxtop & bottom = 1, left & right = 2

      
1px 2px 3pxtop = 1, left & right = 2, bottom = 3

      
1px 2px 3px 4pxtop, right, bottom, left (clockwise)

    

    
Border properties: border, border-left, border-top, border-right, border-bottom, with suffixes -color, -style, -width. Padding: padding, padding-left, … padding-bottom. The border shorthand defines all four sides' properties in a single declaration, e.g. border: 5px outset red;.

3.1
What Is PHP? Request Lifecycle & XAMPP
server-side scripting، والـ htdocs، والـ localhost

  

    
PHP = originally "Personal Home Page", now "PHP Hypertext Preprocessor". A server-side scripting language; PHP code can be embedded in HTML. Used to make pages dynamic: different content depending on context · interface with databases and e-mail · authenticate users · process form information.

    
Some URLs specify programs for the server to run, e.g. http://www.facebook.com/home.php: the server runs home.php and sends back its output (HTML), not the PHP code. Other server-side languages: Java/JSP, ASP.NET, Python, Perl.

    
Why PHP? free and open source · compatible (more than 19 million websites) · simple.

3.2
Syntax, Variables, Types & Arrays
$ قبل كل variable، و ; في آخر كل سطر

  

    
<?php
  echo "Hello, world!";   // single-line comment
  /* multi-line
     comment */
  $username = "Fred Smith";
  $age = 16;
  $drinking_age = $age + 5;
  $this_class_rocks = TRUE;
?>

    
    
      
  • Code between <?php and ?> is executed; everything else is output as pure HTML.
    • 
      
  • Commands end with a semicolon ; · $ is used in front of all variables.
    • 
      
  • Variable names: start with $, then a letter or underscore; contain only a–z, A–Z, 0–9, _; no spaces (use $user_name); case-sensitive: $High_Score ≠ $high_score. So $hello is correct; $ hello, $$hello, $1abc are not.
    • 
      
  • PHP is loosely typed: variables don't have to be declared before use; the type isn't written; PHP converts to the type required by the context (string → int on +, int → float on /). PHP does not support explicit type definition in variable declaration. Use explicit casting when needed, e.g. (int)($a / $b).
    • 
      
  • Types: int, float, boolean, string, array, object. Test with is_string(), is_array()…; gettype() returns the type as a string.
    • 
      
  • Arrays: $team = array('Bill', 'Mary', 'Mike', 'Chris', 'Anne'); → echo $team[3]; prints Chris (index starts at 0). Also valid: $state[0] = "karnataka"; and $state[] = array("karnataka");.
    • 
      
  • 2-D arrays: $oxo[1][2] = third element of the second row.
    • 
      
  • Constants: define("ROOT_LOCATION", "/usr/local/www/"); → cannot be altered; no $ prefix.
    • 
    

  

  

    عالشرح بالعربيالـ variable زي علبة كبريت مكتوب عليها اسم
    
    
      
  • كل variable لازم يبدأ بـ $، وبعده حرف أو _ (مش رقم). وكل أمر بيخلص بـ ;. سؤال Final 2025: «right way of declaring a variable» ← $hello.
    • 
      
  • Case-sensitive: $Name و $name اتنين مختلفين.
    • 
      
  • Loosely typed: مش بتكتب النوع (لا int ولا string). PHP بيعرف لوحده ويحوّل لوحده. عشان كده:
        
    • «PHP supports explicit type definition in variable declaration?» ← False (جه مرتين).
        
    • «variable needs to be declared before it is used?» ← False.

4.1
Relational Operators & Conditionals
if · else · elseif · switch · ? :

  

    
A Boolean is TRUE or FALSE. Three types of relational operators: equality (==) · comparison (> < >= <=) · logical (AND, OR, XOR, NOT). echo prints TRUE as 1 and FALSE as an empty string.

    
if ($bank_balance < 100) {
    $bank_balance += 1000;
} elseif ($bank_balance > 200) {
    $savings += 100;  $bank_balance -= 100;
} else {
    $savings += 50;   $bank_balance -= 50;
}

    
    
      
  • Braces { } may be omitted for a single statement, but using them avoids hard-to-trace bugs.
    • 
      
  • switch: one variable with many values; each case needs break; default runs when nothing matches.
    • 
      
  • Ternary ? takes three operands: echo $fuel <= 1 ? "Fill tank now" : "There's enough fuel";. With $a = 12: ($a == 12) ? 5 : 1 → 5.
    • 
      
  • ⚠️ = assigns, == compares: if ($num = 2) is always true. if ($num == 3); with a semicolon ends the if, so the next line always runs.
    • 
    

  

  

  

    عالشرح بالعربيالفخاخ اللي الدكتور بيحبها 😈
    
    
      
  • == = بيسأل «هل بيساوي؟». = = بيحط قيمة. فـ if ($num = 2) معناها إنك حطيت 2، والـ 2 true، فالشرط دايمًا صح!
    • 
      
  • فخ الـ semicolon: if ($num == 3);، الـ ; بتقفل الـ if فاضية، فالسطر اللي بعدها بيتنفذ دايمًا. ده سؤال 2022 و Quiz 2024 بالظبط.
    • 
      
  • Ternary: شرط ? لو صح : لو غلط، يعني if/else في سطر واحد.
    • 
      
  • switch: لازم break بعد كل case، وإلا هيكمّل وينفّذ اللي بعده.
    • 
    

    
😈
الدكتور وهو بيحط ; بعد الـ if:«خليني أشوف مين ذاكر بجد» 🕵️

    

  






  
4.2
Loops: while · do…while · for
initialization · condition · modification

  

    
Every loop has three parts: initialization · condition · modification.

    

      
// while
$count = 1;
while ($count <= 12) {
  echo "$count times 12 is " . $count * 12 . "<br>";
  ++$count;
}

      
// do...while: at least once
$count = 1;
do
  echo "$count times 12 is " . $count * 12 . "<br>";
while (++$count <= 12);

      
// for
for ($count = 1; $count <= 12; ++$count)
  echo "$count times 12 is " . $count * 12 . "<br>";

    

    
All three print 1 times 12 is 12 … 12 times 12 is 144. do…while checks the condition after the body, so it runs at least once.

  

  

  

    عالشرح بالعربينفس الفكرة بـ ٣ أشكال
    
    
      
  • أي loop = تبدأ منين + تكمّل لحد إمتى + تتحرك إزاي.
    • 
      
  • while = بيسأل الأول وبعدين ينفّذ. do…while = بينفّذ الأول وبعدين يسأل، فبيشتغل مرة على الأقل 🏃. for = الـ ٣ أجزاء في سطر واحد.
    • 
      
  • جرّب الـ tracer اللي فوق ودوس «خطوة» وشوف قيمة $count والـ output.
    • 
    

  






  
4.3
Functions, Scope & include / require
function · return · global · static

  

    
A function is a set of statements that performs a particular operation. It does not execute automatically when the page loads; it runs when called. Advantages: less typing · fewer errors · less loading time · less execution time, since each function is compiled only once.

    
function sum($x, $y) {
    $z = $x + $y;
    return $z;
}
echo "5 + 10 = " . sum(5, 10);   // 5 + 10 = 15

    
    
      
  • Starts with function, then a name (starts with a letter or underscore), then required parentheses with optional comma-separated parameters: function Name(parameters) { body }.
    • 
      
  • return sends a value back; to return several values, return an array. global gives a function access to an outside variable.
    •

    •

    •
